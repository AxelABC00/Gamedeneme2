# Durdanın Tarlaları — Release / Build Guide (Android)

> This is a **prototype** promoted toward a first playable release. For a real production
> release you'd normally graduate the code from `prototypes/` into `src/` with scene files
> and CI (see `.claude/rules/prototype-code.md`). This guide gets a **signed APK** out the
> door from the current build.

## What's already set up (in this folder)
- **App icon** — `icon.png` (256²) + `icon_1024.png`, generated by `_makeicon.gd`. Wired into
  `project.godot` (`config/icon`) and used as the Android launcher icon + boot splash.
- **project.godot** — app name "Durdanın Tarlaları", version 1.0.0, **portrait** orientation,
  mobile stretch (canvas_items / expand), boot splash.
- **Release keystore** — `durdanin-release.keystore` (alias `durdanin`). Details + passwords are
  in `keystore-info.txt`. **Both are gitignored — keep them safe and backed up.**
- **Export preset** — `export_presets.cfg` (Android, arm64 + armv7, signed with the keystore,
  offline: no INTERNET permission). A sanitized `export_presets.cfg.example` is committed.

## What you still need to install (one-time; can't be done headless here)
JDK is already present (Adoptium JDK 21). You need two more things:

### 1. Godot Android export templates (for 4.3-stable)
In the Godot editor: **Editor → Manage Export Templates… → Download and Install**.
(Or download `Godot_v4.3-stable_export_templates.tpz` from the Godot site and install it.)

### 2. Android SDK + build tools
Easiest: install **Android Studio** (bundles the SDK, build-tools, platform-tools).
Then in Godot: **Editor → Editor Settings → Export → Android** and set:
- **Java SDK Path**: `C:/Program Files/Eclipse Adoptium/jdk-21.0.10.7-hotspot`
- **Android SDK Path**: e.g. `C:/Users/ABC-5070/AppData/Local/Android/Sdk`
- **Debug Keystore**: Godot can create one automatically (Editor Settings → Export → Android →
  "Create Android Debug Keystore"), or point it at `~/.android/debug.keystore`.

Verify with **Project → Export…** — the Android preset should show no red errors.

## Build a signed release APK
Once the templates + SDK are set up, from this folder:

```bash
# CLI (headless):
Godot_v4.3-stable_win64_console.exe --headless --path . --export-release "Android" build/durdanin-tarlalari.apk
```

Or in the editor: **Project → Export → Android → Export Project** (uncheck "Export With Debug").

The APK lands in `build/durdanin-tarlalari.apk`.

## Install / test on a device
```bash
adb install -r build/durdanin-tarlalari.apk
```
(Enable USB debugging on the phone first.)

## For Google Play (AAB instead of APK)
Play requires an **.aab**, which needs Godot's **custom Gradle build**:
1. In the Android preset options set **Use Gradle Build = true** and **Export Format = AAB**.
2. Godot: **Project → Install Android Build Template…** (writes `android/build/`).
3. Re-export → produces `build/durdanin-tarlalari.aab`.
This step needs the full Android SDK (build-tools + platform-tools) configured above.

## Updating the app later
Bump **both** in `project.godot` / the preset before each store update:
- `version/code` (integer, must increase every upload) → 2, 3, …
- `version/name` (display string) → "1.0.1", …
Always sign with the **same** `durdanin-release.keystore`.

## Store-listing checklist (Play Console)
- [ ] App icon 512×512 (use `icon_1024.png` downscaled)
- [ ] Feature graphic 1024×500
- [ ] 2–8 phone screenshots (grab from the running game)
- [ ] Short + full description (TR/EN)
- [ ] **Privacy policy URL** (required — the game is offline and collects nothing; a one-page
      "no data collected" policy suffices)
- [ ] Content rating questionnaire (this is an all-ages farming game)
- [ ] Data safety form → "No data collected / shared"

## iOS
iOS export requires **macOS + Xcode** and an Apple Developer account ($99/yr) — it can't be
built on Windows. The project is iOS-compatible (portrait, touch); do the iOS export on a Mac.

## Security reminder
`durdanin-release.keystore` + its passwords are your app's identity forever. Back them up.
Losing them means you can never update the published app.
